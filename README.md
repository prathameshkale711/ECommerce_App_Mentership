 Installation & Setup

 1. Clone the repository

```bash
git clone https://github.com/prathameshkale711/ECommerce_App_Mentership.git
cd ECommerce_App_Mentership
```

### 2. Install dependencies

```bash
npm install
cd client
npm install
```

### 3. Setup environment variables

Create `.env` file in root:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```

### 4. Run the project

```bash
npm run dev
```
